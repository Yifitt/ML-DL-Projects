# 📚 Research Paper Recommendation System

A simple Streamlit app that recommends research papers based on your query using **Sentence Transformers** and **KNN**.

---

## Features

- Enter a topic, abstract, or keyword.
- Get top N recommended papers.
- See paper title, authors, and publication year.
- Fast recommendations using precomputed embeddings.

---
